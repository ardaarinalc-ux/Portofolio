## 🛠️ Sorotan Proyek
* **Smart Exhaust Fan (PID Controller):** Sistem ventilasi dinamis berbasis sensor suhu dan kelembapan ruangan menggunakan algoritma PID pada mikrokontroler.
* **Desain Elektrikal (2D Drafting):** Pemetaan jalur kelistrikan, *Single Line Diagram (SLD)*, dan panel layout menggunakan AutoCAD dengan mengutamakan standar keamanan.
* **Robot Line Follower:** Integrasi sistem mekanikal-elektrikal presisi tinggi dari tahap perakitan hingga penulisan algoritma pergerakan dinamis.

## ⚙️ Cara Menjalankan Secara Lokal
Website ini dibangun menggunakan HTML, CSS, dan vanilla JavaScript tanpa peladen (*backend*) atau *dependency* eksternal. Untuk melihatnya secara lokal:
1. Unduh kode (Download ZIP) atau *clone* repositori ini.
2. Ekstrak file ke komputer Anda.
3. Klik dua kali pada file `index.html` untuk membukanya langsung di *browser* (Chrome, Edge, dll).
